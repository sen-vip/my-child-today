# 👨‍👩‍👧‍👦 우리아이 오늘

**여러 자녀의 급식 · 시간표 · 학교일정을 한눈에**

오늘학교 v1.4.2 완성본을 기반으로 만든 학부모용 확장판입니다.  
기존 오늘학교 저장소와 서비스는 그대로 유지하고, 이 저장소에서만 새 기능을 개발합니다.

예정 주소: `https://sen-vip.github.io/my-child-today/`

---

## v0.2 핵심 기능

### 자녀 여러 명 등록

자녀별로 다음 정보를 묶어 저장합니다.

- 자녀 별칭
- 학교
- 학년
- 반
- 학기

최대 5명까지 등록할 수 있으며, 같은 학교에 다니는 형제·자매도 각각 등록할 수 있습니다.

### 자녀 빠른 전환

상단의 자녀 버튼을 누르면 아래 정보가 선택한 자녀 기준으로 함께 바뀝니다.

- 오늘 학사일정
- 오늘 급식
- 오늘 시간표
- 월별 학교생활 달력
- 선택 날짜 상세
- 공유 링크

자녀를 바꾸면 오늘 날짜로 돌아와 바로 확인할 수 있습니다.

### 자녀 정보 관리

- 자녀 추가
- 별칭·학교·학년·반·학기 수정
- 자녀 삭제
- 마지막으로 본 자녀 자동 복원
- 시간표 카드에서 반을 바꾸면 해당 자녀의 기본 설정에 저장

### 공유 링크 임시 보기

공유 링크로 접속한 학교 정보는 저장된 자녀를 덮어쓰지 않습니다.

- 공유받은 학교를 임시로 표시
- 기존 자녀 목록과 설정 유지
- `내 자녀로 돌아가기`로 원래 화면 복귀

## 저장 방식과 개인정보

자녀 별칭과 학교·학년·반 정보는 사용자의 브라우저에만 저장됩니다.

- 회원가입 없음
- 자체 서버에 자녀 정보 저장 안 함
- 다른 기기와 자동 동기화 안 됨
- 실명 대신 `첫째`, `중학생` 같은 별칭 사용 가능

우리아이 오늘의 저장 키는 기존 오늘학교와 완전히 분리되어 있습니다.

```text
myChildToday.profileState.v1
myChildToday.timetableCache_...
```

기존 오늘학교의 아래 저장값은 읽거나 삭제하지 않습니다.

```text
schoolLifeCalendar.selectedSchool
schoolLifeTimetableGrade
schoolLifeTimetableClass
schoolLifeTimetableSemester
```

## 사용 방법

1. `첫 자녀 등록`에서 자녀 별칭을 입력합니다.
2. 학교를 검색하고 `이 학교 선택`을 누릅니다.
3. 학년·반·학기를 입력하고 `등록 완료`를 누릅니다.
4. 다른 자녀는 상단의 `＋ 자녀 추가`로 등록합니다.
5. 자녀 버튼을 눌러 급식·시간표·학교일정을 전환합니다.
6. `자녀 정보 수정`에서 등록 내용을 변경하거나 삭제합니다.

## 파일 구성

```text

style.css           기존 오늘학교 디자인 + 자녀 프로필 UI

app.js              일정·급식·시간표·달력 및 자녀 전환 로직
server/              기존 공공데이터 프록시 서버
```

## 배포

새 GitHub 저장소 이름은 `my-child-today`를 권장합니다.

1. 이 폴더의 파일을 새 저장소 최상위에 업로드합니다.
2. GitHub 저장소의 `Settings → Pages`로 이동합니다.
3. `Deploy from a branch`를 선택합니다.
4. `main` 브랜치와 `/root`를 선택해 저장합니다.
5. 생성된 주소에서 모바일과 PC 화면을 확인합니다.

기존 `school-life-calendar` 저장소에는 이 파일을 덮어쓰지 않습니다.
