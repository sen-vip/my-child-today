# 👨‍👩‍👧 우리아이 오늘

우리 아이 학교의 **급식 · 시간표 · 학사일정을 한곳에서 확인하는 학부모용 웹앱**입니다.

> **v1.0.8** · 오늘+내일 선조회 및 캐시 경량화

## 주요 기능

- 회원가입 없이 사용
- 자녀 여러 명 등록 및 전환
- 월별 학사일정 확인
- 오늘·내일 급식과 학교생활 확인
- 학년·반 기준 시간표 확인
- 학교 홈페이지·대표전화·주소 바로가기
- 선택한 학교생활 화면 공유
- 등록 정보는 현재 브라우저에 저장

## 화면 구성

### 달력
월별 학교 학사일정을 먼저 확인합니다. 날짜를 누르면 해당 날짜의 학사일정·급식·시간표를 함께 볼 수 있습니다.

### 오늘
오늘의 학사일정, 급식, 시간표와 내일 미리보기를 확인합니다.

### 설정
자녀를 추가하거나 학교·학년·반을 수정하고, 현재 브라우저에 저장된 자녀 정보를 관리합니다.

## 개인정보와 저장 방식

우리아이 오늘은 별도 계정을 만들지 않습니다.

- 자녀 프로필은 현재 브라우저에 저장됩니다.
- 실명 대신 `첫째`, `둘째`, `중학생` 같은 별칭을 사용할 수 있습니다.
- 브라우저 데이터나 사이트 데이터를 삭제하면 등록 정보도 삭제될 수 있습니다.
- NEIS 데이터 캐시에는 자녀 이름이나 별칭을 저장하지 않습니다.
- 공유 링크에는 학교와 학년·반 등 조회 기준이 포함될 수 있지만 자녀 이름·별칭은 포함되지 않습니다.

## 데이터 안내

급식·시간표·학사일정은 **NEIS 공개 데이터**를 사용합니다. 학교의 입력 시점이나 데이터 제공 상황에 따라 실제 학교 안내와 차이가 있을 수 있습니다.

운영 버전에서는 API 조회 실패 시 테스트용 예시 데이터를 대신 표시하지 않습니다.

- 데이터가 없으면 `등록된 ... 정보가 없어요.`로 안내합니다.
- 조회 오류는 `정보를 불러오지 못했어요. 잠시 후 다시 확인해 주세요.`로 구분합니다.
- 같은 날 같은 조회 조건의 NEIS 데이터는 브라우저 캐시를 재사용해 불필요한 반복 호출을 줄입니다.

## 공유

공유 전 최초 1회 안내를 표시합니다. 공유 URL에는 선택한 학교와 학년·반, 날짜 또는 월 정보가 포함될 수 있습니다. 자녀 이름이나 별칭은 공유 URL에 넣지 않습니다.

## 실행 구조

프런트엔드는 정적 웹앱이며 `server/`의 프록시를 통해 NEIS 데이터를 조회합니다.

```text
브라우저 UI
  ↓
NEIS 공통 캐시 계층
  ↓
프록시 서버
  ↓
NEIS 공개 데이터
```

주요 파일:

- `index.html` — 화면 구조
- `style.css` — 반응형 UI
- `app.js` — 화면 상태와 NEIS 조회 로직
- `profile-store.js` — 자녀 프로필 로컬 저장
- `neis-cache.js` — NEIS 데이터 당일 캐시
- `server/server.js` — NEIS 프록시
- `favicon.svg`, `favicon.ico` — 브라우저 탭용 아이콘
- `favicon-16x16.png`, `favicon-32x32.png` — 소형 파비콘
- `apple-touch-icon.png` — iPhone/iPad 홈 화면·즐겨찾기 아이콘
- `android-chrome-192x192.png`, `android-chrome-512x512.png` — Android/Chrome 홈 화면 아이콘
- `android-chrome-maskable-512x512.png` — 마스커블 앱 아이콘
- `site.webmanifest` — 홈 화면 설치용 앱 메타데이터

## v1.0.8 오늘+내일 선조회 및 캐시 경량화

- 오늘 시간표 표시를 우선하고, 완료 직후 내일 시간표를 백그라운드 선조회합니다.
- 월 급식 캐시를 날짜별로 28~31개 복제하던 구조를 제거하고 월 캐시에서 필요한 날짜만 재사용합니다.
- 월말 내일 미리보기는 다음 달 전체 급식·학사일정을 받지 않고 내일 하루만 조회합니다.
- NEIS 캐시 버전을 v2로 올려 기존 중복 일자 캐시를 자동 정리하고, 만료 캐시 보관 기간을 1일로 축소합니다.
- 빈 결과 캐싱·중복 요청 합치기·강제 시간표 새로고침 동작은 그대로 유지합니다.

## v1.0.7 자녀 전환·수정 흐름 개선

- 자녀를 전환해도 보고 있던 날짜와 `달력 / 오늘 / 설정` 탭 유지
- 기존 자녀 정보를 수정한 뒤에도 수정 전 날짜와 탭으로 복귀
- 두 번째 이후 자녀를 추가하면 보고 있던 날짜의 달력으로 이동
- 첫 자녀 등록은 기존처럼 오늘 날짜의 달력으로 이동
- 자녀 전환 직후 이전 자녀 데이터가 섞이지 않도록 런타임 상태를 비운 뒤 새 자녀 데이터 조회

## v1.0.6 복사 결과 자녀 정보 표시

- `오늘 내용 복사`와 `선택 날짜 내용 복사`의 첫 줄에 현재 자녀 별칭·학교·학년·반 표시
- 여러 자녀를 전환해 복사할 때 현재 선택한 자녀 정보만 사용
- 공유받은 임시 화면에서는 별칭을 제외하고 학교·학년·반만 표시
- 자녀 별칭은 복사 텍스트에만 사용하며 공유 URL·캐시 키·NEIS 요청에는 포함하지 않음

## v1.0.5 학기 자동 조회

- 자녀 등록·수정 및 시간표 기준 변경 화면에서 학기 설정 제거
- 선택한 날짜에 대해 1·2학기 시간표를 자동 확인하고 실제 수업 데이터가 있는 결과 표시
- 1~2월 날짜는 전년도 학사연도로 자동 보정해 겨울철 시간표 조회 누락 방지
- 기존 브라우저에 저장된 학기 값은 안전하게 무시하고 이후 저장 시 제거
- 공유 URL에서 학기 값 제거(기존 공유 URL의 학기 값도 무시)
- `여름방학`, `겨울방학`, `휴업일` 등이 교시별 과목처럼 반복 표시되지 않도록 제외
- 방학·휴업일은 시간표 대신 해당 상태를 한 번만 안내

## v1.0.3 모바일 달력 UX 개선

- 모바일에서 월 선택을 왼쪽 정렬하고 `오늘` 버튼을 우측에 분리해 좁은 화면에서 겹치지 않도록 개선
- 모바일 달력 날짜 칸에 대표 학사일정 1개를 직접 표시
- 같은 날 일정이 여러 건이면 `+n`으로 추가 일정 수 표시
- 급식·시간표는 작은 상태점으로만 보조하고, 자세한 내용은 날짜 선택 후 상세 영역에서 확인
- PC에서는 기존 중앙 월 선택 레이아웃 유지

## v1.0.2 로딩 UX 개선

- 350ms 이상 걸릴 때만 통합 로딩 안내 표시
- 학사일정·급식을 동시에 조회하고, 먼저 도착한 정보부터 바로 화면에 반영
- 월 데이터 이후 `거의 다 불러왔어요` 단계로 전환해 시간표 조회 상태 안내
- 4초 이상 걸리면 `처음 연결할 때는 조금 더 걸릴 수 있어요` 안내
- 내일 미리보기와 학교 기본정보는 첫 화면을 막지 않고 뒤에서 갱신
- 학교/월 전환 시 이전 데이터가 잠깐 섞여 보이지 않도록 로딩 상태를 초기화
