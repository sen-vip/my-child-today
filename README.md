# 👨‍👩‍👧‍👦 우리아이 오늘

**여러 자녀의 급식 · 시간표 · 학교일정 · 학교 바로가기를 한눈에**

오늘학교 v1.4.2 완성본을 기반으로 만든 학부모용 확장판입니다.  
기존 오늘학교 저장소와 서비스는 그대로 유지하고, 이 저장소에서만 새 기능을 개발합니다.

예정 주소: `https://sen-vip.github.io/my-child-today/`

---

## v0.3 핵심 기능

### 학교 홈페이지 자동 연결

학교를 검색해 자녀를 등록할 때 나이스 학교기본정보의 홈페이지 주소를 함께 저장합니다.

- 자녀별 학교 홈페이지 바로가기
- 기존 v0.2 자녀는 학교코드로 홈페이지 주소 자동 보완
- 자동 연결되지 않으면 사용자가 직접 주소 수정 가능
- 자녀를 바꾸면 해당 학교 바로가기도 함께 전환

### 공지사항 바로가기

학교마다 공지사항 주소 구조가 달라 사용자가 한 번 직접 등록하는 방식입니다.

1. `학교 홈페이지`를 엽니다.
2. 학교 홈페이지에서 공지사항 게시판으로 이동합니다.
3. 게시판 주소를 복사합니다.
4. `바로가기 설정`에 붙여 넣고 저장합니다.

등록한 주소는 해당 자녀 프로필에만 저장되며, 다른 자녀와 섞이지 않습니다.

### 안전한 외부 링크 처리

- `http://`와 `https://` 주소만 허용
- 주소에 프로토콜이 없으면 `https://` 자동 추가
- `javascript:`, `data:`, `file:` 같은 주소 실행 차단
- 새 탭을 안전한 옵션으로 열기

### 공유 링크 임시 보기

공유 링크로 접속한 학교 정보는 저장된 자녀를 덮어쓰지 않습니다.

- 공유받은 학교의 홈페이지는 임시로 자동 조회
- 개인이 등록한 공지사항 주소는 공유하지 않음
- 기존 자녀 목록과 설정 유지

## v0.2부터 제공하는 기능

### 자녀 여러 명 등록

자녀별로 다음 정보를 묶어 저장합니다.

- 자녀 별칭
- 학교
- 학년
- 반
- 학기
- 학교 홈페이지 주소
- 공지사항 주소

최대 5명까지 등록할 수 있으며, 같은 학교에 다니는 형제·자매도 각각 등록할 수 있습니다.

### 자녀 빠른 전환

상단의 자녀 버튼을 누르면 아래 정보가 선택한 자녀 기준으로 함께 바뀝니다.

- 오늘 학사일정
- 오늘 급식
- 오늘 시간표
- 월별 학교생활 달력
- 선택 날짜 상세
- 학교 홈페이지·공지사항 바로가기
- 공유 링크

### 자녀 정보 관리

- 자녀 추가
- 별칭·학교·학년·반·학기 수정
- 자녀 삭제
- 마지막으로 본 자녀 자동 복원
- 시간표 카드에서 반을 바꾸면 해당 자녀의 기본 설정에 저장

## 저장 방식과 개인정보

자녀 별칭과 학교·학년·반, 직접 등록한 학교 링크는 사용자의 브라우저에만 저장됩니다.

- 회원가입 없음
- 자체 서버에 자녀 정보 저장 안 함
- 다른 기기와 자동 동기화 안 됨
- 실명 대신 `첫째`, `중학생` 같은 별칭 사용 가능
- 공지사항 내용을 수집하거나 저장하지 않음

우리아이 오늘의 저장 키는 기존 오늘학교와 완전히 분리되어 있습니다.

```text
myChildToday.profileState.v1
myChildToday.timetableCache_...
```

기존 오늘학교의 아래 저장값은 읽거나 삭제하지 않습니다.

```text
schoolLifeCalendar.selectedSchool
schoolLifeTimetableGrade
schoolLifeTimetableClass
schoolLifeTimetableSemester
```

## 사용 방법

1. `첫 자녀 등록`에서 자녀 별칭을 입력합니다.
2. 학교를 검색하고 `이 학교 선택`을 누릅니다.
3. 학년·반·학기를 입력하고 `등록 완료`를 누릅니다.
4. 다른 자녀는 상단의 `＋ 자녀 추가`로 등록합니다.
5. 자녀 버튼을 눌러 급식·시간표·학교일정을 전환합니다.
6. `학교 홈페이지` 버튼으로 학교 사이트를 엽니다.
7. `공지사항 등록` 또는 `바로가기 설정`에서 공지 게시판 주소를 저장합니다.

## 배포

새 GitHub 저장소 이름은 `my-child-today`를 권장합니다.

### GitHub Pages

1. 이 폴더의 파일을 새 저장소 최상위에 업로드합니다.
2. GitHub 저장소의 `Settings → Pages`로 이동합니다.
3. `Deploy from a branch`를 선택합니다.
4. `main` 브랜치와 `/root`를 선택해 저장합니다.
5. 생성된 주소에서 모바일과 PC 화면을 확인합니다.

### 프록시 서버

v0.3의 홈페이지 자동 연결을 사용하려면 `server/server.js`도 배포 서버에 반영해야 합니다.  
`/api/schools` 응답에 나이스 `HMPG_ADRES` 값을 `homepageUrl`로 전달하도록 변경되었습니다.

기존 `school-life-calendar` 저장소에는 이 파일을 덮어쓰지 않습니다.
