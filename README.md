# 👨‍👩‍👧‍👦 우리아이 오늘

**여러 자녀의 오늘·내일 급식, 시간표와 학교일정을 한눈에 확인하는 학부모용 웹앱**

기존 `오늘학교` 완성본을 기반으로 만든 별도 확장판입니다. 기존 저장소와 배포 주소는 그대로 유지하고, 이 저장소에서만 부모용 기능을 개발합니다.

예정 주소: `https://sen-vip.github.io/my-child-today/`

---

## v0.4.1 핵심 기능

### 부모형 가독성·접근성 개선

- 오늘·내일 카드의 핵심 본문과 날짜 글자 확대
- 자녀 선택 카드의 이름·학교 정보 가독성 향상
- 학교정보의 학교명·전화번호·주소를 10~15% 확대
- 전화·복사·홈페이지 버튼을 44px 이상 터치 영역으로 통일
- `접기/펼치기` 글자 버튼을 44px 화살표 버튼으로 단순화
- 학교정보 재확인을 관리용 텍스트 동작으로 낮춰 정보 위계 개선
- 작은 회색 문구의 색상 대비 강화
- 키보드 본문 바로가기와 명확한 초점 표시 추가
- 모바일에서는 전화·복사 버튼을 넓게 배치

### 오늘·내일 부모 홈

- 오늘 급식
- 오늘 시간표
- 오늘 학교일정
- 내일 급식 미리보기
- 내일 학교일정 미리보기
- `내일 자세히 보기`로 기존 날짜 상세 화면 연결

내일이 다음 달인 경우에도 필요한 달의 데이터만 추가 조회합니다.

### 자동 학교정보 카드

학교를 검색해 자녀를 등록하면 나이스 학교기본정보에서 다음 항목을 자동으로 저장합니다.

- 학교 주소
- 대표전화
- 학교 홈페이지

학교정보 카드는 모바일에서 기본적으로 접어 두고, 펼치면 다음 기능을 사용할 수 있습니다.

- 대표전화 바로 걸기
- 전화번호 복사
- 학교 주소 복사
- 학교 홈페이지 열기
- 학교정보 다시 확인

학부모가 홈페이지 주소나 전화번호를 직접 입력할 필요는 없습니다.

### 기존 데이터 자동 보완

v0.2 또는 v0.3에서 등록한 자녀는 다시 등록하지 않아도 됩니다.

- 학교코드로 기존 자녀의 학교정보를 다시 조회
- 비어 있는 주소·대표전화·홈페이지 자동 보완
- 급식·시간표·일정 조회와 별도로 처리하여 실패해도 핵심 기능 유지

### 공지사항 기능 처리

v0.3의 공지사항 주소 직접 등록 화면은 v0.4에서 제거했습니다.

- 기존에 저장된 `noticeUrl` 값은 삭제하지 않음
- 메인 화면과 자녀 설정에서는 노출하지 않음
- 향후 자동 공지 기능을 검토할 때 호환용으로 유지

## 자녀 여러 명 등록

자녀별로 다음 정보를 묶어 저장합니다.

- 자녀 별칭
- 학교
- 학년
- 반
- 학기
- 학교 기본정보

최대 5명까지 등록할 수 있으며, 같은 학교에 다니는 형제·자매도 각각 등록할 수 있습니다.

상단 자녀 버튼을 누르면 다음 정보가 함께 전환됩니다.

- 오늘·내일 정보
- 월별 학교생활 달력
- 선택 날짜 상세
- 학교정보 카드
- 공유 링크 기준

## 저장 방식과 개인정보

자녀 별칭과 학교·학년·반 정보는 사용자의 브라우저에만 저장됩니다.

- 회원가입 없음
- 자체 서버에 자녀 정보 저장 안 함
- 다른 기기와 자동 동기화 안 됨
- 실명 대신 `첫째`, `중학생` 같은 별칭 사용 가능

우리아이 오늘의 저장 키는 기존 오늘학교와 분리되어 있습니다.

```text
myChildToday.profileState.v1
myChildToday.timetableCache_...
myChildToday.schoolInfoExpanded
```

기존 오늘학교의 저장값은 읽거나 삭제하지 않습니다.

## 사용 방법

1. `첫 자녀 등록`에서 자녀 별칭을 입력합니다.
2. 학교를 검색하고 `이 학교 선택`을 누릅니다.
3. 학년·반·학기를 입력하고 `등록 완료`를 누릅니다.
4. 다른 자녀는 상단의 `＋ 자녀 추가`로 등록합니다.
5. 자녀 버튼을 눌러 오늘·내일 정보와 학교정보를 전환합니다.
6. 학교정보를 펼쳐 전화·주소·홈페이지 기능을 사용합니다.

## 배포

새 GitHub 저장소 이름은 `my-child-today`를 권장합니다.

### GitHub Pages

1. 이 폴더의 파일을 새 저장소 최상위에 업로드합니다.
2. `Settings → Pages`로 이동합니다.
3. `Deploy from a branch`를 선택합니다.
4. `main` 브랜치와 `/root`를 선택해 저장합니다.
5. 생성된 주소에서 모바일과 PC 화면을 확인합니다.

### 프록시 서버

v0.4의 자동 학교정보 기능을 사용하려면 `server/server.js`도 배포 서버에 반영해야 합니다.

`/api/schools` 응답에 다음 나이스 항목을 전달합니다.

```text
ORG_RDNMA  → address
ORG_TELNO  → phoneNumber
HMPG_ADRES → homepageUrl
```

프록시 서버를 갱신하기 전에도 기존 급식·시간표·학사일정 기능은 사용할 수 있습니다. 다만 대표전화 자동 보완은 서버 갱신 후 작동합니다.
